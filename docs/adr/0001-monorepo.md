# ADR 0001: Monorepo

## Contexto
(Por que tenho 3 partes: back-end, front-end e infra?)
- 


## Decisão
Usar um único repositório com as pastas backend/, frontend/ e infra/.

## Consequências
- Positivas: 
    - Facilita o entendimento do projeto como um todo
    - Facilita a execução de testes
    - Facilita a execução do projeto
- Negativas: 
    - Maior complexidade
    - Código desorganizado
    - Código duplicado
